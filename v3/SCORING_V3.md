# V3：一致性门控与物理评分

一致性分记为 `C ∈ [0,1]`，通过阈值默认 `τ = 0.8`。VLM 只评估视频内部的时序视觉连贯性，物理规律的正确性仍由原有测量器判断。

| 情况 | 运行物理流程 | 最终分数 | score_status |
| --- | --- | --- | --- |
| C ≥ τ，物理指标全部可测 | 是 | 0.15C + 0.85P | complete |
| C ≥ τ，物理指标部分可测 | 是 | 0.15C + 0.85P | partial |
| C ≥ τ，物理指标全部不可测 | 是 | 0.15C | unavailable |
| C < τ | 否 | 0.15C | consistency_rejected |
| VLM 评测失败 | 否 | null | consistency_error |
| 已通过门控，但物理程序发生错误 | 已尝试 | 保留 0.15C，按现有结果记录物理贡献 | execution_error |

`P` 是所有**已定义物理指标的纯物理分等权平均**。已定义但提取失败的指标贡献 0，未定义指标不进入分母；原始物理测量公式、尺度与提取有效性检查保持不变。V2 的每指标 0.15 识别奖励不再计入 V3 总分。

例如 `C = 0.8`、`P = 0.5` 时总分为 `0.12 + 0.425 = 0.545`；`C = 0.2` 未通过默认门槛，物理后端不执行，总分为 `0.03`。即使物理量无法提取，只要一致性评测有效，其 15% 部分仍保留。

## 一致性规则

默认采样 8 帧，包含视频首尾。参考图和生成提示词只保留在审计记录中，不发送给 VLM，也不用于判断场景是否相同。背景、地面、镜头、视角、光照、颜色、物体布局和风格变化都不影响一致性分；静止、遮挡、进出画面和动作是否完成也不影响一致性分。

中等程度的持续视觉不连贯也应被扣分并可能被门控拦截：同一主体反复改变主要轮廓、类别、部件数量、连接关系或身份，非遮挡导致的部件反复出现/消失/复制/融合，重复的橡皮筋式拉伸或不合理形变，以及背景稳定时无法解释为正常运动的瞬移。单独一帧的瑕疵、运动模糊、透明/遮挡、透视变化、场景切换或背景/地面/布局/颜色变化不算失败。刚性装置的拓扑突然改变也属于严重扭曲，例如 U 形管在视频中变成矩形容器。

评分锚点为：`0.90–1.0` 基本稳定，`0.70–0.89` 有局部或轻微重复不稳定，`0.50–0.69` 有持续但主体仍可辨认的结构/身份不稳定，`0.00–0.49` 为明显或长时间的拓扑变化、复制、融合/分裂或画面破坏。纯运动模糊且主体轮廓/身份/连接稳定时仍应给 0.90 以上。代码统一根据 `C >= τ` 决定通过，因此中等结构异常会在物理评测前被拦截。

不平衡的液面、错误的速度/轨迹或不守恒的水量交给物理后端评估。评分模型只返回分数和观察理由，代码统一根据 `C >= τ` 决定通过，模型输出中的额外“通过”字段不会覆盖阈值规则。

## 输出语义

公开结果继续保留八个顶层字段和两个物理指标。总分读取 `verbose.M1._scoring_summary.score`，不能直接平均 `metrics.M1/M2.metric` 得到总分。

- `verbose.M1._consistency` 保存 VLM 判断；`status=evaluated` 才是有效判分。
- `_scoring_summary` 包含 `consistency_score`、`consistency_passed`、`consistency_contribution`、`physics_score`、`physics_contribution` 和 `physics_attempted`。
- 一致性未通过时，`physics_score=null`、`physics_contribution=0`，已定义指标的 `extract_success=false`、`metric=null`、`measurement_attempted=false`、`status=not_run`。这表示未执行物理测量，不能解释为已证实违反物理规律。
- 未定义指标继续保留 `extract_success=null`、`metric=null`。
- 已执行物理评测时，`metrics.M1/M2.metric` 是纯物理分；原始测量值仍保存在 `verbose.M*.raw_metric`。
- 本地加载或 HTTP 服务异常、非法 JSON、越界/非有限分数等都记录为评测错误，不自动放行，也不伪装成一致性 0 分。
- 命令退出码：`0` 表示完成且有物理量可测；`1` 表示有效门控拒绝或物理量不可测；`2` 表示配置/模型/运行错误。

一致性结果不读取已有物理分，不复用之前的通过结论。每次运行重新采样并调用 VLM；分割、跟踪缓存准备与物理子进程均位于门控通过之后。
